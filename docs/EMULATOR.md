# 전용 Android 에뮬레이터 v0.8

이 APK는 **hakuX 1.3.0 기반 드라이버 개조판**이며 원 개발자의 공식 배포가 아닙니다. 원본 hakuX v1.3.0의 커밋은 `a90f01ee4629977b36a76175cbd781d383056293`입니다.

## 변경 내용

- `HLE_XBE_MAX_SECTIONS`: 256 → 512. 원본 게임의 398개 구역 및 v0.8 롬의 399개 구역을 읽기 위한 변경입니다.
- 검증한 **Mesa Turnip 26.0.0-R8** 패키지 동봉. Qualcomm KGSL/Adreno 드라이버 로딩을 지원하는 환경에서 첫 실행 때 앱 내부에 풀고 활성화합니다.
- 앱 이름 `hakuX Spikeout KR`, 버전 `1.3.0-spikeout-kr-v0.8`, 버전 코드 10.
- 별도 설치 식별자 `com.rfandango.haku_x.spikeoutqa`. 기존 QA 설치본의 서명을 유지해 업데이트할 수 있으며, 공식 앱과 별도입니다.
- 처음 설정할 때 해상도 1배, 콘솔 드라이브 시간 재현 끄기, 네트워크 끄기, 디버그 지연 표시 끄기를 기본값으로 지정합니다. 이미 저장된 해당 설정값은 유지합니다.
- Android NDK r30을 선택할 수 있는 빌드 속성을 추가했습니다.
- 고정한 libslirp 4.7.0의 콜백 형식에 맞춰 NAT 코드의 반환 타입 이름을 `ssize_t`로 맞췄습니다.

**Mesa 드라이버만 순정 1.3.0에 넣으면 게임 실행 파일 로더의 256개 제한은 그대로입니다.** 따라서 동일한 드라이버를 선택해도 이 게임의 원본·한글판 실행 실패를 해결하지 못합니다. 전용 APK의 로더 수정과 그래픽 드라이버 변경은 별개의 변경입니다.

확인 환경은 Android 13 / Adreno 740입니다. 다른 GPU에는 별도 호환 그래픽 드라이버가 필요할 수 있습니다. 현재 PC 에뮬레이터에서 정상 플레이를 확인하지 못했으며, PC 지원용 APK가 아닙니다. PC·다른 에뮬레이터는 호환성이 개선된 후속 버전을 기다리거나 패치 실행이 가능한 Xbox 실기를 고려해주세요. 실기 실행은 미검증입니다.

일부 배경 광원의 미세한 그래픽 깨짐이 남아 있습니다. v0.8의 새 자막 테두리와 드라이버 자동 설치 흐름은 기기 연결이 끊긴 뒤 추가됐으므로 실기 재검증 전입니다. 동봉 드라이버와 네이티브 코어는 정상 화면을 확인한 기존 검증본과 동일합니다.

## 대응 소스와 빌드

릴리스의 `hakuX-Spikeout-KR-source-v0.8.zip`에는 수정된 hakuX 소스, 실제로 사용한 FEX 소스와 네이티브 의존성, 수정 차이, 라이선스 및 빌드 스크립트가 포함됩니다. 서명 개인 키와 기기 데이터는 포함하지 않습니다.

소스 묶음을 푼 뒤 그 안의 `BUILD.md`와 `build-emulator.sh`를 따르세요. JDK 21, Android SDK 36 / Build Tools 36.1.0, NDK r30과 CMake/Ninja가 필요합니다. 사용한 네이티브 CPU 대상은 `armv8.2-a+fp16+dotprod+rcpc`입니다. Kotlin/Android 라이브러리는 Gradle이 저장소에서 받습니다.

동일 기능을 다시 빌드할 수 있도록 소스를 제공하지만, 로컬 디버그 서명과 빌드 시각 등으로 APK의 전체 파일 해시는 달라질 수 있습니다.
